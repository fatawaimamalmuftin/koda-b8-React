langkah instal react dan css tailwind
1. npm create vite@latest nama-project-kamu -- --template react < untuk install package react
2. npm install < menginstal folder node_moduls
3. npm install tailwindcss @tailwindcss/vite < untuk nginstal package tailwind yg akan di tambahkan di vite config
4. di file vite.config.js tambahkan > import tailwindcss from '@tailwindcss/vite' > di dalam export default tambahkan > tailwindcss() < masang plugins
5. di ./index.css hapus semua ganti @import "tailwindcss"; untuk mengimport tailwindcss nya
6. tesnya di app.jsx
